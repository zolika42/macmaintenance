# Public release review — 1.3.0 RC

Scope: reconstructed 1.2.3 source matching the supplied 1.2.3 patch (reverse apply checked), followed by the 1.3.0 permission changes. Reviewed source structure, permission paths, privileged operations, distribution scripts and test scope. This is a source review, not a complete penetration test, notarization, or native certification. Linux core tests cannot exercise AppKit, launchd, TCC, AppleScript authentication, APFS/DMG, or real macOS Trash.

| Component | Observed controls / finding | Gate |
|---|---|---|
| Scanner / Advanced | Allowlisted cache roots, bounded scans, metadata/symlink checks; scan-to-move is not atomic. Browser cache excludes profiles. Docker pruning is a separate explicitly approved permanent operation. | Native tests on test data, symlink/race and Docker coverage required |
| FullRemoval / Uninstaller | Bundle identity and reviewed paths, no Apple/system/self removal; exact IDs preselected, shared and name-only uncertain items separately handled. User's CCleaner report shows seven residual service plists and two name-only paths. A failed step can leave partial removal. | BLOCK: complete authenticated service inventory and post-removal checks; fixture including inaccessible plists, actual real app regression |
| ServiceRemoval | App-level authorization fallback is scoped to non-Apple bundles in /Applications. Native osascript approval, root quarantine. RootMoveScript checks inode but ancestor chain was checked outside privilege boundary; must recheck in privilege context and address path substitution and cross-device mv. Disabled launchd jobs may persist after removal; private root quarantine has no full UI restore / purge lifecycle. | BLOCK: privileged-operation threat model, reviewed minimal helper / atomic same-volume move, recovery, cancellation, relaunch and reinstall tests |
| Permissions / Readiness | Added first-launch review, FDA read-only directory probes, App Management settings link, optional native harmless admin test and notification request. No public API to promise all TCC grants. Settings review is not an authorization token. | BLOCK: native tests with granted, denied, revoked, non-admin, and fresh ad-hoc build |
| Storage / Monitor | Bounded large file and hash sampling, system commands for read-only metrics; history keeps local paths. No exhaustive duplicate detection. Some system commands may fail or be unavailable. | Native runtime, memory and battery tests |
| Recovery / history | Cache receipts verify source identity and avoid overwrite. Other moves are only recorded; privileged quarantine has no integrated restore workflow. History stored in user's Library. | BLOCK: privileged recovery; test history path integrity, retention and corrupt history handling |
| Updates | Local-only SHA-256 checks; no publisher-authenticated network manifest. New users do not require developer project directory. | Network update optional; never advertise it until implemented and tested |
| Build / release / install | Ad-hoc signing, strict code signature verification and DMG checksum/content check; source installer requires Xcode but public DMG does not. ARM64 only, declared macOS 14 minimum, native acceptance only documented on developer Mac. | BLOCK: download from HTTPS to clean Mac, verify Gatekeeper behavior without disabling protections, run actual installed app, test minimum OS or adjust support claim |
| License / privacy | Package.swift declares no external Swift package dependencies. Source has local commands and no implemented telemetry/remote updater; dependency/tool and asset license provenance still needs confirmation. | BLOCK: final license/privacy notices and asset audit |

## Acceptance gates (no real personal files)
- Clean account / separate test Mac: download exact release DMG over HTTPS, verify checksum, install, launch with Gatekeeper intact, decline and grant each relevant permission, restart as requested, revoke and retry; standard-user versus administrator behavior.
- Test a disposable signed test app with launchd KeepAlive, root-owned app bundle, root-owned service plist (including unreadable plist), helper and SQLite data. Assert service disabled/unloaded before stop; no relaunch; precise per-path results; successful removal or accurate partial state; no unrelated paths touched. Test password cancellation, unsafe symlinks, identity changes, and denied App Management.
- Test cache preview and restore, Docker pruning on disposable local data only, monitor, storage, startup, security, preferences, notifications, install rollback. Test older supported macOS or narrow the support statement.
- Perform independent privilege/security review and full license/asset review; publish clear beta label, support and privacy terms, checksums and verified download URL only after approval.
