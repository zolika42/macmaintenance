# MacMaintenance
A cleaner Mac. Without the subscription.

Free and open-source (GPLv3) native macOS maintenance for Apple Silicon. Review and clean caches, uninstall applications and associated verified data, explore disk usage, monitor your system, and review security settings. No account, ads, subscription or implemented telemetry. Optional signed online update checking.
