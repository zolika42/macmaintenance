# MacMaintenance 2.0.0 — Public Beta candidate

Free native maintenance for Apple Silicon Macs. Includes cache review and cleanup, application removal with reviewed data and service handling, storage visualization, monitoring, security status, permission setup and optional authenticated online release checking and automatic DMG download (manual installation). No subscription, ads or implemented telemetry. Source code is available under GPL-3.0-only; contributions via pull requests are welcome.

Ad-hoc signed, not notarized. macOS can warn or block. Use only the official download, verify SHA-256 and follow Apple's official instructions; do not disable Gatekeeper or SIP. Some protected/shared/unverified components can remain. Back up your data. Minimum supported macOS version must be verified before release. No Intel build.
